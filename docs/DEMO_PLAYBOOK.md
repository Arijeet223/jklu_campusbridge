## 🏆 Key Talking Points for Judges & Evaluators

1. **Deterministic Shell, Probabilistic Core:** We never let an LLM decide eligibility or calculate fit scores. Cutoffs and rubrics run 100% deterministically in pure Python/SQL.
2. **Visual Provenance:** Every claim is backed by a document ID, page span, and 6-tier evidence badge. Clicking any span opens the original PDF source.
3. **No Biometric Surveillance:** Micro-defenses are 100% asynchronous and text-based. No invasive webcams, emotion AI, or voice accent scoring.
4. **DPDP Compliance by Construction:** Opt-in consent, small-cell suppression ($< 5$), versioned audit ledgers, and one-click data export/erasure.
5. **55/55 Passing Tests:** Complete automated coverage across domain logic, hybrid RAG, scoped MCP servers, red-team adversarial attacks, and agent workflows.
